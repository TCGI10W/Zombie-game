# Dead Protocol: Nacht Outbreak

Round-based zombie survival shooter made with Godot 4.7 (GDScript), with
Steam co-op for up to 8 players. See [COOP_README.md](COOP_README.md).

## How to play
1. Download **Godot 4.7.1** from https://godotengine.org/download
   (the standard version is enough; the project has no C#).
2. Download this repository (green **Code** button → **Download ZIP**) and unzip it.
3. Start Godot, choose **Import**, pick `project.godot` in the unzipped folder,
   then press **Run** (F5). The first open takes a few minutes while Godot
   imports the assets.

For online co-op, start **Steam** before the game.
